# Point of Sale System

A four-page CodeIgniter 4 application created for IT0049 TFA1.

## Pages

- Home: `/`
- About: `/about`
- Customer Accounts: `/customers`
- User Accounts: `/users`

## Local setup

1. Run `composer install`.
2. Rename `env` to `.env`.
3. Set the `app.baseURL` in `.env`. http://localhost/cadag/tfa1/
4. Copy the `app.baseURL` in `.env` to `public string $baseURL` in `App.php`.
5. Open `http://localhost/cadag/tfa1/`.
